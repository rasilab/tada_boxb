# Plasmid sequences

The plasmids used in this study, as listed in the manuscript's supplementary table of plasmids.

| File | Contents |
| --- | --- |
| [plasmids.csv](./plasmids.csv) | Every plasmid, its genotype, and the GenBank file here carrying its sequence |

Each sequence is a GenBank file named after its plasmid identifier and genotype. Two plasmids are
other groups' constructs and are not redistributed here: TadA8.20, from
[Xiao et al. 2023](https://doi.org/10.1038/s41587-022-01587-6), and pAGMnase, which is
[Addgene #123461](https://www.addgene.org/123461/).
